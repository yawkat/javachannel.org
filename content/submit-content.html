This submission form is currently closed because of system migration. Contact me (yawkat) directly should you wish to submit an article.

Feel free to submit your own content for publication! If you think it’s worth telling the wider Java community about it, you probably should – and yes, if you create a useful factoid, that’s worth writing up as a submission.
It will go through an editing process for suitability and presentation (and if it’s not quite ready for prime time, you’ll be informed, as long as we have your actual contact information), and be published as soon as is possible.

The submission form of the old site is gone. To submit content, talk to us in #java on Libera.Chat or open a pull request against the site's repository.

Feel free to post tiny snippets of code to the channel – but note that two lines is the limit. If you need to display any real amount of code, please use a pastebin.
Here are some you can use for static (nonrunning) pastes:

  • https://gist.github.com
  • https://www.hastebin.com
  • https://paste.gg

For runnable snippets, try:

  • https://glot.io/new/java
  • https://ideone.com
